# AGENTS.md

Единственный источник правил проекта — `CLAUDE.md` в корне. Прочитай его целиком до первого действия, затем `docs/case/case-455-talenttrack.md` и `docs/case/qa-2026-09-02.md`.

Пять правил, которые нельзя нарушить даже в черновике:

1. Сигнал на дату T — только по данным, опубликованным не позже T. `tests/test_no_lookahead.py` должен проходить.
2. Каждый пуш объясняется фактом из базового индикатора; генеративных моделей в сигнальном контуре нет.
3. Только открытые воспроизводимые данные; клиентских и персональных — нет.
4. Определения (курс, дата публикации, попадание, база, lift, выгода) — из словаря в `CLAUDE.md` и ADR в `docs/decisions/`; менять только новым ADR.
5. Тексты пушей — факты о прошлом и настоящем, без прогнозов и обещаний; прогон `uv run fxmoment check-texts`.
