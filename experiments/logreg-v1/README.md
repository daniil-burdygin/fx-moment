# Эксперименты: модель-агрегатор V1, доп. индикаторы, стек и регулярность потока

Исследовательский стенд поверх пакета `fxmoment` (06.09.2026, Олег Андреев). Здесь проверялось, что даёт модель-агрегатор из спецификации V1 и слайда «Как устроена модель», если менять обучающие данные, модели на входе логрега и набор индикаторов, а признаки, зафиксированные для текстов пушей, оставить как есть. Метрики считаются у всей системы: индикаторы → модель → калибровка → единый порог и гейт → политика → `fxmoment.metrics.evaluate_events`.

Стенд не входит в пакет и не пересобирает `reports/`: это отдельные скрипты, которые читают `data/raw/` через `fxmoment.data.store.load_panel` и пишут в `results/`.

## Что здесь

| Файл | Что делает |
|---|---|
| `harness.py` | стенд v1: pooled-логрег на признаках пяти коридоров, порог по частоте на окне порога, гейт по уровню, политика, метрики; варианты задаются JSON-спеками |
| `harness2.py` | стенд v2 по схеме слайда: скоры базовых моделей (бустинг, лес, extra-trees, kNN, Байес, регрессия выгоды) out-of-fold по временным блокам → логрег → калибровка Platt → единый порог (`fpw`, `lift`, `utility`, `rolling`) → политика; плюс метрики регулярности по всем валютам вместе |
| `weights.py` | веса логрега по окнам walk-forward и вклад признаков в отправленные пуши |
| `summarize.py`, `summarize2.py` | сводные таблицы и парные сравнения по парам «коридор × окно» с бутстрепом |
| `specs/` | JSON-спеки всех прогнанных вариантов |
| `results/` | результаты: `all_results.csv` (v1, 94 варианта), `all_results_v2.csv` (v2, 49 вариантов), `weights_*.csv`, `events_FINAL_*.json` (даты пушей выбранного варианта), `rows_*.csv` (метрики по окнам) |
| `Итоги_v1_индикаторы_и_модели.md` | отчёт первой серии: цели, данные, модели, доп. индикаторы |
| `Итоги_v2_стек_и_регулярность.md` | отчёт второй серии: стек скоров в логрег, порог, гейт, регулярность |

## Запуск

Из корня репозитория, после `uv sync --group dev`:

```bash
uv run python experiments/logreg-v1/harness.py experiments/logreg-v1/specs/specs_final.json experiments/logreg-v1/results/my.csv
uv run python experiments/logreg-v1/harness2.py experiments/logreg-v1/specs/specs2_F.json experiments/logreg-v1/results/my2.csv
uv run python experiments/logreg-v1/weights.py
```

Один вариант логрега считается за секунду, стек с бустингом — 20–30 секунд, с лесом — минуты. Скрипт пропускает варианты, уже записанные в выходной CSV.

## Устройство стенда

- **Разбиение.** 11 тестовых полугодий 2021-01…2026-06 из `fxmoment.backtest.walkforward.make_splits`. Перед тестом окно порога 12 месяцев, зазоры по 20 дней с обеих сторон: обучение → зазор → окно порога → зазор → тест.
- **Цель.** По умолчанию «средний курс следующих 20 дней не ниже сегодняшнего минус 25 бп», то есть та же разметка, что в метрике «по среднему». Варианты: горизонт 10, строгий минимум, локальный минимум ±20, знак выгоды.
- **Признаки.** Зафиксированные для текстов: ранги уровня 60/120/250, серии, доходности 5/20, провал к средней 60, расстояние до минимума 60, гармоники месяца. Доп. группы: волатильность, техника (RSI, z-score, MACD, просадка, наклон MA), USD-контекст, корзина EUR/CNY, календарь.
- **Нормировка.** RobustScaler по медиане и межквартильному размаху обучающего окна, внутри пайплайна.
- **Порог.** Один на пять коридоров: квантиль под целевую частоту, «максимум пушей при lift на окне порога ≥ 1,3», асимметричная полезность или скользящий квантиль по хвосту 120 дней.
- **Политика.** Пауза 3 дня после пуша, не больше двух пушей за 7 дней на коридор. Сверка факта с курсом приложения не моделируется.

## Главные результаты

| Вариант | lift медиана | lift pooled | выгода сверх случайного дня, бп | пушей/нед. | 2-нед. периодов с пушем |
|---|---|---|---|---|---|
| Логрег строго по спеке: зафиксированные признаки, без гейта | 0,91 | 0,91 | +4 | 0,49 | 51 % |
| Логрег + доп. индикаторы, без гейта | 1,09 | 1,08 | +62 | 0,58 | 71 % |
| **Логрег + доп. индикаторы, гейт rank120 ≤ 0,3** | **1,39** | **1,27** | **+97** | 0,40 | 49 % |
| Стек бустинг → логрег, гейт 0,3, скользящий порог | 1,36 | 1,34 | +129 | 0,33 | 49 % |
| Правило «уровень» при той же частоте | 1,32 | 1,24 | +82 | 0,34 | 41 % |
| Календарь «первый день с 25-го» | 1,20 | 1,12 | +45 | 0,23 | 46 % |

Выводы, которые вошли в презентацию и в `docs/product/limitations.md`:

1. Логрег на одних зафиксированных признаках хуже случайного дня; его вытягивают гейт по уровню и доп. индикаторы, из них решает группа техники.
2. Скоры классических моделей на входе логрега качества не добавляют: без гейта любой набор даёт lift ≈ 1,0–1,06, с гейтом стек не лучше логрега без скоров.
3. Против правила «уровень» при той же частоте модель не отличается по lift (разность +0,04, интервал через ноль), выигрывает по выгоде на пуш (+100 бп, интервал выше нуля).
4. Точность куплена редкостью: гейт по уровню молчит в растущем режиме, 2023-I без единого пуша на всех валютах. Регулярность решается вторым семейством фактов, а не другой моделью.
5. В логреге больше всего весят ранг курса за год, ранг доллара за полгода и ранг местной валюты к доллару: хороший день — курс на квартальном минимуме, но не на годовом, и просел он за счёт рубля.

## Оговорки

Все варианты отобраны на одних и тех же 11 окнах, лучшие цифры оптимистичны. Порог по частоте вместо асимметричной полезности из спеки в v1, эпизоды ARMED/OPEN и LOCO-гейт стабильности не реализованы, сверка с курсом приложения и окно доставки по местному времени не моделируются.
