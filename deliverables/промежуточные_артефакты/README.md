# Промежуточные артефакты к сдаче 04.09.2026 10:00 МСК

Папка повторяет четыре пункта карточки Talent Track: в каждой подпапке лежит ровно то, что грузится в этот пункт. Один комплект на всю команду.

| Пункт карточки | Что принимает форма | Подпапка | Файлы |
|---|---|---|---|
| Презентация проекта | `.pdf` или `.pptx`, до 2 файлов | `1_Презентация_проекта/` | `Презентация_промежуточная.pdf` — 16 слайдов; `Презентация_промежуточная.html` — исходник той же презентации |
| Описание проекта | `.md`, 1 файл | `2_Описание_проекта/` | `Описание_проекта_промежуточное.md`; та же копия в `deliverables/interim/` |
| Продуктовые материалы | `.pdf`, `.xlsx`, `.md`, до 10 файлов | `3_Продуктовые_материалы/` | `Продуктовая_рамка.md` — ответы по шести пунктам карточки, вклад AI Product, таблица «продуктовое решение → ADR → код»; копии `concept.md`, `texts.md`, `pilot.md`, `limitations.md`, `star-task.md`, `market.md` из `docs/product/` |
| Дополнительные материалы | любой формат и ссылки, до 10 файлов | `4_Дополнительные_материалы/` | машина времени и интерактивный разбор метрик (HTML, работают офлайн); README четырёх отчётов; графики `chart_TJS.png`, `frontier.png`, `day_of_month.png`, `cbr_vs_moex_by_hour.png` |
| Репозиторий команды | ссылка, обязательно | — | <https://github.com/daniil-burdygin/fx-moment> |

Ограничения формы взяты из самой карточки (атрибут `accept` полей загрузки), а не из описания пункта: продуктовые материалы `.md` принимают, а `.html` и `.png` — нет, поэтому интерактивные страницы и графики идут в дополнительные.

В дополнительных ровно десять файлов — это потолок пункта. Поэтому из пяти графиков коридоров оставлен один, TJS: остальные лежат в репозитории.

Все числа в презентации и описании взяты из отчётов репозитория, пересобранных на одном коммите после слияния окна клиента и машины времени. Копии документов сделаны на том же коммите; при изменении оригиналов копии нужно обновить.

Презентация собирается из HTML печатью в PDF:

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless --disable-gpu \
  --no-pdf-header-footer --virtual-time-budget=20000 \
  --print-to-pdf="$PWD/Презентация_промежуточная.pdf" \
  "file://$PWD/Презентация_промежуточная.html"
```

Правки текста — в HTML-файле, затем повторная печать. Страница 1280×720 пикселей даёт лист 960×540 пунктов, то есть 16:9.
