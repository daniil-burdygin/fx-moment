# Промежуточные артефакты к сдаче 04.09.2026 10:00 МСК

Папка повторяет четыре пункта карточки Talent Track: в каждой подпапке лежит ровно то, что грузится в этот пункт. Один комплект на всю команду, загружает Даниил.

| Пункт карточки | Подпапка | Файлы | Обязательно |
|---|---|---|---|
| Презентация проекта (PPTX или PDF, до 2 файлов) | `1_Презентация_проекта/` | `Презентация_промежуточная.pdf` — 15 слайдов; `Презентация_промежуточная.html` — исходник той же презентации, открывается в браузере | да |
| Описание проекта (Markdown) | `2_Описание_проекта/` | `Описание_проекта_промежуточное.md` — версия от 04.09 с вечерними результатами 03.09 и разделом «Команда и распределение задач»; та же копия лежит в `deliverables/interim/` | да |
| Продуктовые материалы (до 10 файлов) | `3_Продуктовые_материалы/` | `Продуктовая_рамка.md` — ответы по шести пунктам карточки, вклад AI Product и таблица «продуктовое решение → ADR → код»; копии `concept.md`, `texts.md`, `pilot.md`, `limitations.md`, `star-task.md` из `docs/product/` на коммите `7280800` | да |
| Дополнительные материалы | `4_Дополнительные_материалы/` | README отчётов `reports/latest`, `reports/latest/analysis`, `reports/intraday` (сверка источников и прогон на часовой оси); графики коридоров `chart_*.png`, `frontier.png`, `day_of_month.png`, `cbr_vs_moex_by_hour.png`; `Окна_и_метрики_интерактивный_разбор.html` — интерактивный разбор расчёта метрик на данных отчёта; ссылка на репозиторий: <https://github.com/daniil-burdygin/fx-moment> (приватный, доступ по запросу) | нет |

Все числа в презентации и описании взяты из отчётов репозитория на коммите `7280800` (снимок курсов ЦБ от 2026-09-03). Копии документов из `docs/product/` и `reports/` сделаны на том же коммите; при изменении оригиналов копии нужно обновить.

Презентация собирается из HTML печатью в PDF (Chrome, страница 1280×720). Правки текста — в HTML-файле, затем повторная печать.
