## Расхождения README с реальностью

README сейчас переписывает Олег — ниже список правок, не патч.

1. 🧩 **`fetch` и `fetch-moex` стоят первыми строками блока.** Кто читает блок сверху вниз,
   первым делом идёт в сеть и переписывает `data/raw/` свежей выгрузкой ЦБ — после этого
   побайтовое воспроизведение закоммиченных отчётов невозможно. Пометить обе строки
   «обновление снимка, для воспроизведения не нужно» и увести вниз, под `pytest`.
2. 🧩 **`prototype/` в таблице «Что где»: «ещё не собран, каталога в репозитории нет».**
   Каталог есть, в нём `README.md` и `timemachine.html` (Ш9). Строку переписать.
3. 🧩 **В блоке команд нет `compare-runs`, `timemachine`, `client-window`.** Первая нужна,
   чтобы понять вариантные прогоны из таблицы `reports/`; вторая — экспонат защиты.
4. 🧩 **`signals` показан без `--decide --texts`.** Сквозной сценарий защиты — именно
   `signals --as-of 2026-06-22 --decide --texts`; без флагов команда печатает только события,
   без решения политики и текстов. Дату в README (`2026-06-15`) свести с датой сценария.
5. 🧩 **Нет ожидаемого времени шагов.** `backtest` идёт 2,5 минуты, печатая всё в конце —
   выглядит как зависание. Проставить «≈2,5 мин» и «≈2 мин» у `backtest` и `pytest`.
6. 🧩 **Не сказано, что прогон воспроизводит закоммиченные отчёты побайтово.** Это прямой
   балл по критерию 4 (прототип и пилот) и по критерию 3 (обоснованность): одна строка
   «после `backtest` и `analyze` `git status` показывает изменившимися только `provenance.json`
   и два `README.md` — числа совпадают побайтово» стоит абзаца текста.
7. 🧩 **`uv run ruff check .` в README нет вовсе**, хотя `CLAUDE.md` требует его перед PR.
8. 🧩 **Строка «Без uv» неработоспособна как записана.** `python3.12` на чистой macOS нет
   (uv ставит свой), `pip install -e .` не ставит группу `dev` — `pytest` и `ruff` не появятся,
   и завершается строка снова `fetch`, то есть походом в сеть. Либо чинить все три места,
   либо убрать: uv в README уже назван обязательным.
9. 🧩 **Раздел «Статус» датирован 03.09** и не знает работы ночи 04.09: окна клиента (Ш5),
   машины времени (Ш9), времени отправки по поясам (Ш2). Пересобрать по `docs/STATUS.md`.
10. 🧩 **`uv run pytest -q` прячет итог.** В `pyproject.toml` уже стоит `addopts = "-q"`,
    вторая `-q` глушит строку `113 passed`: видны только точки. В README форма верная
    (`uv run pytest`) — стоит добавить оговорку, чтобы её не «улучшили» флагом.

Битых ссылок в README нет: четыре относительные ссылки открываются, таблица `reports/`
перечисляет ровно те шесть каталогов, что лежат в репозитории.
