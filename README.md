# fx-moment — сигнальный слой «выгодный момент для перевода за рубеж»

AI Product Hack 2026 (AI Talent Hub × ИТМО), кейс 455 Альфа-Банка. Команда 9.

Источников два: дневной фиксинг ЦБ РФ и часовые свечи Московской биржи. По коридорам RUB→TJS/UZS/KGS/AMD/KZT проект считает сигналы «сейчас выгодно» и «окно закрывается» и прогоняет их walk-forward бэктестом без заглядывания вперёд. Меряются lift над случайным днём, выгода в базисных пунктах, частота и кучность; из индикаторов собирается поток триггеров под лимит 1–2 пуша в неделю, а тексты пушей проходят чекер запрещённых формулировок. Условия кейса дословно — [docs/case/case-455-talenttrack.md](docs/case/case-455-talenttrack.md), ответы кейсодателя — [docs/case/qa-2026-09-02.md](docs/case/qa-2026-09-02.md).

## Запуск

Нужны Python 3.12 и [uv](https://docs.astral.sh/uv/). Данные тянутся с сайта ЦБ РФ (`cbr.ru/scripts/XML_dynamic.asp`) и с ISS Московской биржи (`iss.moex.com`); снимки на дату выгрузки лежат в `data/raw/` — без сети всё воспроизводится по ним.

```bash
uv sync --group dev                 # окружение и зависимости
uv run fxmoment fetch               # курсы ЦБ 2015→сегодня по 8 валютам → data/raw/cbr_daily.csv
uv run fxmoment fetch-moex          # часовые свечи Мосбиржи 2018→сегодня → data/raw/moex_hourly.csv
uv run fxmoment backtest            # walk-forward бэктест всех индикаторов → reports/latest/
uv run fxmoment analyze             # цена ожидания, перенос, фронтир, помесячная база, форма месяца
uv run fxmoment backtest --fixed-params      # контрольный прогон без калибровки → reports/fixed/
uv run fxmoment compare-sources     # сверка биржевого закрытия с фиксингом ЦБ → reports/intraday/
uv run fxmoment intraday            # тот же бэктест на часовой оси → reports/intraday/
uv run fxmoment signals --as-of 2026-06-15   # сигналы, как они выглядели бы на дату среза
uv run fxmoment check-texts         # прогон библиотеки текстов через чекер запрещённых формулировок
uv run pytest                       # тесты, включая тест на отсутствие заглядывания вперёд
```

Без uv: `python3.12 -m venv .venv && . .venv/bin/activate && pip install -e . && fxmoment fetch`.

## Статус

Состояние работы, цифры бэктеста и следующие шаги — [docs/STATUS.md](docs/STATUS.md); отчёт последнего прогона — `reports/latest/README.md`, анализы — `reports/latest/analysis/README.md`. Главное на 03.09. На горизонте 1–5 дней ряд ЦБ не отличим от случайного блуждания. Сигнал есть на горизонте месяца: уровень даёт lift 1,05–1,16 и +39…+70 бп сверх случайного дня на всех пяти коридорах, обучаемый и провал к тренду — до 1,5 на отдельных. Моментум и «окно закрывается» не работают. Точность покупается редкостью: фронтир в `analysis/frontier.png`, полоса 1–2 в неделю читается как потолок. Часовая ось биржи не даёт ни момента внутри дня (lift 0,94–1,05 на CNY), ни частоты: медиана 0,00–0,50 пуша в неделю против 0,38–0,65 на дневной оси. Календарное правило без индикаторов «первый день публикации с 25-го» даёт lift 1,12 и +71 бп — стек его не обгоняет, и оно становится нижним слоем продукта. Факт пуша доживает до утра у 93 % пушей; разворот меряется как сожаление с даты последнего `BUY_NOW` (медиана +33 бп по пушам), а не как прогноз.
