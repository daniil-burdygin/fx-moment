# fx-moment — сигнальный слой «выгодный момент для перевода за рубеж»

AI Product Hack 2026 (AI Talent Hub × ИТМО), кейс 455 Альфа-Банка. Команда 9.

На открытых дневных курсах ЦБ РФ по коридорам RUB→TJS/UZS/KGS/AMD/KZT проект считает сигналы «сейчас выгодно» и «окно закрывается», прогоняет их walk-forward бэктестом без заглядывания вперёд, меряет lift над случайным днём, выгоду в базисных пунктах, частоту и кучность, собирает из индикаторов поток триггеров под лимит 1–2 пуша в неделю и подбирает тексты пушей в рамках комплаенса. Условия кейса дословно — [docs/case/case-455-talenttrack.md](docs/case/case-455-talenttrack.md), ответы кейсодателя — [docs/case/qa-2026-09-02.md](docs/case/qa-2026-09-02.md).

## Запуск

Нужны Python 3.12 и [uv](https://docs.astral.sh/uv/). Данные тянутся с сайта ЦБ РФ (`cbr.ru/scripts/XML_dynamic.asp`), снимок на дату выгрузки лежит в `data/raw/` — без сети всё воспроизводится по нему.

```bash
uv sync --group dev                 # окружение и зависимости
uv run fxmoment fetch               # курсы ЦБ 2015→сегодня по 8 валютам → data/raw/cbr_daily.csv
uv run fxmoment backtest            # walk-forward бэктест всех индикаторов → reports/
uv run fxmoment signals --as-of 2026-06-15   # сигналы, как они выглядели бы на дату среза
uv run fxmoment check-texts         # прогон библиотеки текстов через чекер запрещённых формулировок
uv run pytest                       # тесты, включая тест на отсутствие заглядывания вперёд
```

Без uv: `python3.12 -m venv .venv && . .venv/bin/activate && pip install -e . && fxmoment fetch`.
