Определения у нацбанков разные, и складывать их строки между собой нельзя. НБ КР считает переводы через системы, мобильные приложения и электронные кошельки по отчётности комбанков, причём с 2022 года охват расширен. ЦБ РА считает все переводы физлиц через коммерческие банки Армении и отдельно выделяет некоммерческие. ЦБ РУз даёт трансграничные денежные переводы. В ряду ЦБ РФ перечисления из России учтены целиком, вместе с переводами на собственные счета за рубежом.

## Что не удалось найти

**Страновой ряд ЦБ РФ после 2021 года.** База [1] отдаёт 2006–2021 и в годовом, и в квартальном разрезе: запрос кварталов до IV 2022 возвращает только четыре квартала 2021 года, служебный ответ `getyearslist` — `{"fromY":2006,"toY":2021}`. Файлы «Личные переводы», «Личные переводы между Россией и странами СНГ» и их детализированные компоненты помечены «Дата последнего обновления: 15 апреля 2022 г.» и заканчиваются 2021 годом. На странице статистики внешнего сектора весь блок стоит под заголовком «Ретроспективный блок». Последний обзор — «Трансграничные переводы физических лиц в 2021 году».

**Разбивка по странам-отправителям у Нацбанка Таджикистана.** Сайт nbt.tj 04.09.2026 недоступен: HTTPS падает на сертификате, HTTP отдаёт 403 с заглушкой Fortinet, домен резолвится в 208.91.112.55 (Fortinet Inc.) и через Google DoH, и через Cloudflare DoH. Сторонний серверный фетчер, валидатор W3C, получает тот же 403, при этом nbkr.kg с него открывается — блокировка не локальная. По архивным снимкам самого НБТ разбивки по странам он не публикует в принципе: её нет ни в меню «Статистика», ни в банковском статбюллетене, ни в файлах платёжного баланса. Максимум из первоисточника — агрегаты платёжного баланса за 2024 год: первичные доходы 4 455,4 млн $, вторичные 1 721,0 млн $, без деления по странам. Поэтому по TJS «из России» взято из [1] за 2021 год и из матрицы [7].

**Таблица переводов по странам у ЦБ Узбекистана.** Её нет ни в разделе статистики, ни в статистическом бюллетене (75 листов, оглавление без строки о переводах), ни в открытых данных. Страновая разбивка существует только текстом в годовом отчёте за 2024 год. В отчёте за 2025 год её уже нет — там только сальдо первичных и вторичных доходов, 371 млн $ и 13,7 млрд $.

**Годовой итог переводов через СМДП у НБ РК.** Публикуются только помесячные PDF; декабрьский выпуск сравнивает декабрь с ноябрём и года не подводит.

**Матрица KNOMAD свежее 2021 года.** Домен knomad.org снят целиком: любой адрес, включая прямые ссылки на xlsx, редиректит на страницу Всемирного банка. Данные достаются через API data360 и веб-архив; более поздней версии матрицы нет.

## Как перезамерить

```bash
# ЦБ РФ: сумма переводов из России, 2021 год (последний в ряду)
curl -sS -X POST "https://www.cbr.ru/hd_base/tg/" \
  --data "Direction=1&IsYearSum=1&FromDateY=2021&ToDateY=2021&PokGroup=0&PokName=CO_total_sum&CC_51=on&CC_398=on&CC_417=on&CC_762=on&CC_860=on"
# проверить, не открыли ли ряд заново:
curl -sS "https://www.cbr.ru/hd_base/tg/getyearslist/"   # сейчас {"fromY":2006,"toY":2021}

# Всемирный банк: приток личных переводов, все пять стран
curl -sS "https://api.worldbank.org/v2/country/TJK;UZB;KGZ;ARM;KAZ/indicator/BX.TRF.PWKR.CD.DT?format=json&per_page=500"

# Двусторонняя матрица: REF_AREA — отправитель, COMP_BREAKDOWN_1 — получатель
curl -sS -A "Mozilla/5.0" "https://data360api.worldbank.org/data360/data?DATABASE_ID=WB_KNOMAD&INDICATOR=WB_KNOMAD_BRE&REF_AREA=RUS&COMP_BREAKDOWN_1=WB_KNOMAD_TJK"
```
