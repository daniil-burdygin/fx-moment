## Итоговый поток

Ни один вариант не сдвигает поток за пределы интервала. `all`: 1,047 → 1,047 / 1,050 / 1,055 / 1,033;
`BUY_NOW`: 1,041 → 1,037 / 1,039 / 1,053 / 1,021. Форма не меняется: пушей 735 → 744 / 731 / 741 / 745,
медианы частоты по коридорам те же, кучности нет ни у кого.

Одно исключение показывать честно: у `ml-timesfm` выгода потока +26,8 → +29,4 бп с интервалом по
парам [+0,4; +5,1] — целиком выше нуля. По окнам тот же разрыв даёт «разницы нет», и верить надо
второму: пять коридоров здесь почти одно наблюдение. Прибавка идёт от `BUY_NOW` (+34,3 → +37,9 бп),
но сам обучаемый на этом прогоне по выгоде теряет (−0,7 бп) — то есть двигается не точность
индикатора, а состав того, что дожило до отправки через ранг и охлаждение.

## 🧩 Рекомендация по слоту обучаемого

**Слот остаётся за базовым `LearnedMinimum` без дополнительных признаков.** Основания:

1. Ни один вариант не отличим от базового по lift и по выгоде ни в одном из двух блоков. Мержить
   любой из них в `latest` значит сдвинуть все числа обучаемого в презентации, описании и
   `limitations.md` накануне защиты ради эффекта внутри интервала.
2. TimesFM в продукт не идёт при любом исходе: веса 3.0 под TimesFM Non-Commercial License v1.0,
   которая прямо запрещает production и client deliverables. Признаки и снимок остаются в репозитории
   как контроль замера, за флагом, и в стек не включаются.
3. У EUR/USD лучший из четырёх результат (+0,034 lift, +5,4 бп) и он бесплатен по данным — те же
   курсы ЦБ. Но интервал через ноль в обоих блоках, а на AMD признак статистически теряет. Ветку
   `feat/eurusd-feature` закрыть, признак оставить за флагом: возвращаться к нему на данных пилота,
   где событий будет больше, а не на этих 266.
4. Общее обучение (pooled) — единственный вариант, который поднимает UZS выше единицы (0,98 → 1,07,
   а вместе с EUR/USD 1,09 при интервале [+0,03; +0,23]). Это довод не за слот, а за продуктовую
   заметку: слабый коридор лечится чужими строками, и на данных банка проверять надо это, а не
   внешние признаки.

Что это даёт защите: слот обучаемого проверен четырьмя способами, включая сильнейший из доступных
зеро-шот прогнозистов, и ни один не побил базовый. Отрицательный результат с интервалами — ответ на
вопрос «а вы пробовали модель посильнее».

## Строки для `limitations.md`

- **Внешние признаки обучаемому индикатору ничего не дают.** Слот проверен четырьмя способами на
  одних 11 окнах: EUR/USD как заменитель индекса доллара, признаки прогноза TimesFM 3, общее
  обучение на пяти коридорах и общее обучение с EUR/USD. Pooled lift 1,156 → 1,190 / 1,168 / 1,188 /
  1,159, выгода +37,0 → +42,4 / +36,3 / +38,5 / +35,4 бп; все двадцать интервалов разницы содержат
  ноль и по парам «коридор × окно», и по окнам (`docs/decisions/ml-matrix.md`, `reports/ml-*/vs_latest/`).
  По отдельным коридорам знак не держится: EUR/USD прибавляет на KZT и теряет на AMD, общий с
  EUR/USD прибавляет на UZS. Правило устойчивости ADR-0004 не выполняется ни у одного варианта.
- **Готовый прогнозист временных рядов не даёт ничего сверх фактов.** TimesFM 3 (Google, зеро-шот,
  0,3 млрд параметров) проверен на 14 298 прогнозах по пяти коридорам и USD. Как признаки обучаемого
  индикатора — 1,156 → 1,168 при [−0,064; +0,083], выгода −0,7 бп при [−17; +13]. Навык самого
  прогноза замерен отдельно и тоже отрицателен. Ошибка медианы на месяц к ошибке «курс не изменится»
  0,99–1,03, доля угаданных знаков 0,45–0,55 при доле большинства 0,51–0,53, а как правило `BUY_NOW`
  прогноз хуже случайного дня (lift 0,96–0,97, −20…−30 бп) — ветка `feat/timesfm-feature`,
  `docs/decisions/timesfm-experiment.md` и `reports/timesfm/analysis/` там же. Единственное, что
  модель умеет, — калиброванная полоса 10–90 % шириной около ±5 % на месяц, и она повторяет нашу
  таблицу достижимости уровней 90/95/99 %. Веса под некоммерческой лицензией, в продукт не идут.

## Воспроизвести

```
uv run fxmoment backtest --ml-features eurusd --out ml-eurusd
uv run fxmoment compare-runs --variant ml-eurusd --pair ml_localmin=ml_localmin
uv run fxmoment backtest --ml-features timesfm --out ml-timesfm
uv run fxmoment compare-runs --variant ml-timesfm --pair ml_localmin=ml_localmin
uv run fxmoment backtest --ml pooled --ml-features eurusd --out ml-pooled-eurusd
uv run fxmoment compare-runs --variant ml-pooled-eurusd --pair ml_localmin=ml_localmin
```

Снимок прогнозов лежит в репозитории (`data/derived/timesfm_daily.csv`, 14 298 строк, хеш снимка ЦБ
в метаданных); пересобрать и проверить его самопроверкой — `uv sync --group forecast && uv run
fxmoment fetch-forecast` (около 15 минут на M3 Pro, код 1 значит «самопроверка не сошлась, снимок не
записан»). Прогон `ml-pooled` сделан 03.09 на коммите `32c8677`, три остальных — 06.09 на `629e98a`.
