# ADR-0008 — Целевая вероятность подтверждения: 90 % как рабочая точка

**Контекст.** Условия называют 90/95/99 % как шкалу самопроверки порогов; кейсодатель: уровень выбирает и обосновывает команда. Асимметрия цены ошибки требует высокой точности; полоса частоты 1–2 в неделю ограничивает, насколько высокой.

**Решение.** Рабочая точка — **90 %** hit rate на h = 5 для `BUY_NOW` при tol = 0. Для каждого коридора строится **фронтир «частота — точность»**: hit rate и частота при порогах 80/85/90/95/99 %; полоса [1, 2] в неделю рисуется на графике, рабочая точка выбирается как самая высокая точность внутри полосы. Если 90 % недостижимы внутри полосы — точка сдвигается вниз и это пишется в отчёт как ограничение коридора.

**Обоснование.** 95 и 99 % на дневном ряду ЦБ, по предварительным прогонам, выбивают частоту из полосы на большинстве коридоров; 90 % оставляет 1 из 10 пушей ошибочным — цена, которую компенсирует выгода в бп при lift ≥ 1,3. Решение проверяемо графиком, а не спором.

**Следствия.** Матрица отчёта содержит строки для трёх уровней; фронтир — обязательный график защиты.

**Статус.** Принято 03.09.2026. Пересматривается по результатам полного бэктеста 04–05.09.
