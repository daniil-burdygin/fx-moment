# ADR-0005 — Объяснимость: ML решает «когда», факт объясняет «почему»

**Контекст.** Условия: сигнал должен быть объясним, «мы обязаны уметь показать, на каком основании отправлено сообщение»; генеративные модели в сигнальный контур не идут; обучаемый индикатор обязателен и определяет, оказался ли день локальным минимумом в окне ±h с порогом под асимметричную цену ошибки.

**Решение.**

1. Обучаемый индикатор — классификатор (`HistGradientBoostingClassifier`, при необходимости логистическая регрессия как эталон) на признаках, производных от базовых индикаторов и контекста USD/RUB: длина серии снижения, процентили уровня на окнах 20/60/120/250, расстояние от минимума и максимума окна, доходности за 1/5/20 дней, реализованная волатильность, месяц, день недели. Разметка: локальный минимум в окне ±h (h = 10, две недели в каждую сторону — под месячный горизонт решения, ADR-0004) с допуском 10 бп.
2. **Гейт объяснимости.** Пуш по ML-индикатору отправляется только когда одновременно истинен хотя бы один факт базового индикатора (уровень в нижних p %, серия снижения ≥ N, отскок от минимума ≥ r бп). Текст пуша строится из этого факта. ML без факта = `WATCH`, не пуш.
3. Порог классификатора выбирается на отложенной части обучающего окна (последние 20 %) по **асимметричной выгоде**: для каждого порога средняя выгода вперёд по срабатываниям, где отрицательная выгода (ошибочный пуш) взвешена в 3 раза; допустимы пороги с долей срабатываний ≥ 6 % дней до гейта. Та же асимметрия — в весах обучения (класс «не минимум» × 3). Соотношение 3:1 — допущение, чувствительность в отчёте. Первый вариант «точность ≥ 90 %» отброшен 03.09: при базе ≈ 30 % (tol = 0) порог уходил в 95-й процентиль и давал 0,02–0,08 сигнала в неделю.
4. **Скорость** индикатора — метка класса: моментум `fast`, уровень `medium`, разворот `slow`, сезонность `slow`, ML — по факту-гейту. **Сила** — 0…1: для уровня глубина процентиля (1 − p/p_max), для моментума длина серии к N_max окна калибровки, для разворота отскок к r_max, для ML — вероятность.
5. Для отчёта и защиты — важность признаков и монотонные ограничения там, где знак очевиден (глубже процентиль — выше вероятность минимума).

**Обоснование.** Объяснение «модель так решила» не проходит комплаенс и не проходит критерий 3; факт-гейт даёт объяснение, пригодное для текста пуша, и защищает от срабатываний модели вне знакомых состояний.

**Следствия.** ML не может повысить частоту выше частоты фактов — он только выбирает лучшие дни из них. Это и есть его роль.

**Статус.** Принято 03.09.2026.
