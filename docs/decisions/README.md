## Замеры — не ADR, решение не принято

Файл замера отвечает на «что дали числа», а не «как мы решили»; в ADR он превращается только вместе с решением Даниила.

| Замер | Что мерилось | Исход |
|---|---|---|
| [ml-matrix](ml-matrix.md) | пять строк слота обучаемого: базовый · +EUR/USD · +TimesFM · общий · общий +EUR/USD | все интервалы через ноль; 🧩 слот остаётся за базовым |
| [pooled-ml-experiment](pooled-ml-experiment.md) | один обучаемый на пять коридоров вместо пяти своих | +0,032 lift при интервале через ноль |
| [level-drift-experiment](level-drift-experiment.md) | уровень на ряде с вычтенным дрейфом локальной ноги | работает на KGS и UZS, ломается на KZT; в стек не идёт |
| [precision-experiment](precision-experiment.md) | полоса допустимости калибровки: кривая из четырёх точек — без полосы, 0,3–0,5, 0,1–0,3 и 0,05–0,15 сигнала в неделю | pooled lift правил 1,041 → 1,057 → 1,062 → 1,068, все интервалы через ноль; поток 735 → 505 пушей; 🧩 в продукт не берём |
| [ruble-signal-experiment](ruble-signal-experiment.md) | один сигнал по USD/RUB на все пять коридоров вместо пяти своих | суммарный lift не сдвинулся (1,041 → 1,041), калибровок 66 вместо 330; 🧩 в стек до сдачи не переносим |
| [holidays-experiment](holidays-experiment.md) | правило «k дней публикации до праздника» на 755 нерабочих днях шести стран | как сигнал «сейчас выгодно» не работает нигде (pooled lift 0,70–0,89); предпраздничные дни хуже случайного — 🧩 кандидат в фильтр политики |
| [holiday-filter-experiment](holiday-filter-experiment.md) | предпраздничное окно как фильтр политики: K = 5 и K = 3 против `latest` | поток 735 → 625 пушей, `BUY_NOW` lift 1,041 → 1,063 и выгода +34 → +45 бп; семь интервалов из восьми через ноль; 🧩 решение за Даниилом |
| [evening-gate-experiment](evening-gate-experiment.md) | вечернее движение фьючерсов Мосбиржи против факта пуша, снятого с рынка до 15:30 | снимает 15 пушей из 332; у снятых факт доживает до утра в 4 случаях из 15 против базовых 93 %, точности оставшимся не добавляет |
| [minfin-experiment](minfin-experiment.md) | операции Минфина по бюджетному правилу как признак режима дня | режим двигает базу случайного дня, а не сигнал: интервалы разниц содержат ноль, признак обучаемому не добавлен |
