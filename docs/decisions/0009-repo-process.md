# ADR-0009 — Репозиторий и процесс

**Контекст.** Трое участников, у каждого свой ИИ-агент; жюри оценивает воспроизводимость, честность и «команду людей и ИИ» (роли, процесс, измеримое ускорение).

**Решение.**

1. `main` — всегда воспроизводим: `uv sync && uv run pytest` проходит. Рабочие ветки `feat/<что>`, PR с зелёными тестами; документацию можно править в `main` напрямую.
2. Коммиты от имени участника, который вёл работу (в том числе с агентом); сообщение по-русски в повелительном наклонении, одно изменение — один коммит.
3. Любое допущение, влияющее на метрики или продукт, — ADR до кода.
4. Результаты в `reports/` — только из CLI, с датой снимка данных и хешем коммита.
5. Журнал работы с ИИ — `docs/process/ai-workflow.md`: что делал агент, сколько заняло, что переделывали руками. Это материал для критерия «люди + ИИ».
6. Репозиторий приватный на время хакатона; доступ жюри — по ссылке-приглашению или переключением в публичный перед Demo Day.

**Статус.** Принято 03.09.2026.
