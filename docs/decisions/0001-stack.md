# ADR-0001 — Стек: Python 3.12, uv, pandas/scikit-learn

**Контекст.** Команда — продакт и два AI-инженера первого курса; жюри и кейсодатель проверяют воспроизводимость по README; хакатон длится пять дней.

**Решение.** Python 3.12 через `uv` (lock-файл, одна команда установки). Библиотеки: pandas, numpy, scikit-learn (обучаемый индикатор — `HistGradientBoostingClassifier`, без lightgbm/xgboost), matplotlib, requests. Код — пакет `src/fxmoment` с CLI `fxmoment`; ноутбуки только для исследования.

**Обоснование.** Один язык для всей команды и её агентов; sklearn ставится без компиляторов на любой машине; бустинг из sklearn закрывает требование «классический ML» и объясним через важность признаков и монотонные ограничения. Lock-файл `uv.lock` даёт постороннему повторение результата бит в бит по зависимостям.

**Следствия.** Всё, что попадает в отчёт, считается командой CLI и пишется в `reports/`. Ноутбук — не доказательство.

**Статус.** Принято 03.09.2026.
