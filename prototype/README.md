# Прототипы и демо

- `timemachine.html` — машина времени: сигналы «как на дату T» (строка Ш9 плана). Собирается из
  `reports/latest` командой `uv run fxmoment timemachine`. Открывается офлайн. Ряды, решения политики
  и тексты — из отчёта, вердикты попаданий — теми же функциями `labels`, что в бэктесте; скрипт
  страницы только скрывает всё после T и по кнопке раскрывает следующие 20 дней публикации. Журнал
  попаданий на дату T считает лишь пуши, чей горизонт закрылся не позже T. В подвале — хеш кода
  прогона и снимок данных: после пересборки отчётов страницу пересобрать той же командой, иначе она
  показывает прежний прогон.
- Живая проверка среза на защите — `uv run fxmoment signals --as-of <дата> --decide --texts`. На
  2026-06-22 команда работает 10 с (замер 04.09.2026 на ноутбуке, CPU) и считает состояние
  индикаторов и решение политики заново. Страницу она не читает.
- `index.html` — экран «момент изменился» и журнал попаданий, строки Ш3 и Ш10. Разбор ниже.
- `journey.html` — кликабельный клиентский путь из пуша в перевод на визуальном языке Альфа-Онлайн,
  с развилкой «сигнал устарел». Разбор в конце файла.

## `index.html` — «момент изменился» и журнал попаданий

Один файл, CSS и JS внутри, ни одного внешнего запроса: открывается двойным щелчком без сервера и
без сети. Рамка повторяет интерактивный концепт команды — слева заголовок шага, в центре телефон
390 × 844, справа панель «Действия», внизу дисклеймер.

Четыре состояния переключаются панелью справа, клавишами 1–4 и параметром адреса:
`index.html?state=actual` · `changed` · `closed` · `journal`; `&how=1` открывает страницу с уже
раскрытым «Как рассчитано».

| Состояние | Что показывает | Механика |
|---|---|---|
| `actual` | пуш открыт вечером 09.06.2026: предзаполненная форма, курс a_T, факт с окном, «Как рассчитано» | предзаполнение (`star-task.md`, «Предзаполнение формы») |
| `changed` | тот же пуш открыт 22.06.2026: две цифры, дельта в сомони и рублях, форма сохранена | A, «честная дельта» |
| `closed` | тот же пуш открыт 01.07.2026: факт больше не выполняется, экран говорит это первой строкой | A в худшем сценарии |
| `journal` | последние 12 пушей коридора с вердиктом «сбылось / не сбылось / ещё идёт» | Ш10, «пуш, который сам себя оценивает» |

### Как пересчитать журнал

Вердикт считает сама страница: `verdict()` в `index.html` сравнивает `mean20` с
`rate × (1 − 25 / 10⁴)` — это `labels.hit_buy_now(..., mode="mean")` из ADR-0003. «Ещё идёт» стоит
там, где горизонт не закрылся на дату журнала (22.06.2026), и `mean20` в данных равен `null`:
задним числом вердикт не подставляется.

Пересобрать массив `JOURNAL` после нового прогона:

```python
import json, pandas as pd
from fxmoment.data.calendar import to_publication_panel
from fxmoment import labels

rate = to_publication_panel(pd.read_csv("data/raw/cbr_daily.csv"))["TJS"].dropna()
mean20 = labels.future_mean(rate, 20)
dec = pd.read_csv("reports/latest/stream_decisions.csv")
sent = dec[(dec.corridor == "TJS") & (dec.decision == "sent")].tail(12)
as_of = pd.Timestamp("2026-06-22")
for _, row in sent.iterrows():
    t = pd.Timestamp(row["date"])
    pos = rate.index.get_loc(t)
    known = rate.index[pos + 20]          # день, когда вердикт стал известен
    print(t.date(), row["rate"], None if known > as_of else round(mean20[t], 5), known.date())
```

Дата журнала выбрана той же, что у состояния `changed` и у сквозного сценария защиты
(`signals --as-of 2026-06-22`), чтобы все четыре экрана рассказывали одну историю.

### Токены дизайна

Взяты из открытой дизайн-системы Альфа-Банка `core-ds/core-components` **на глаз**: сети в сессии
нет, npm не подключён, значения выписаны в `:root` файла руками. Точен один акцентный красный

при подключении пакета заменяется его переменными; иконок и шрифтов из пакета не берётся ничего,
всё нарисовано CSS, а флаг — эмодзи системного шрифта.

### Что здесь 🧩, а не решение

- Даты открытия (22.06 и 01.07), сумма 10 000 ₽, получатель, банк и назначение — выбор агента.
- «Извините, сигнал устарел» противоречит пункту 20 `star-task-research.md` («экран не извиняется»).
  Формулировка взята из постановки задачи; если побеждает пункт 20, первую строку состояния
  `closed` надо переписать на факт без извинения.
- Порог экрана расхождения 25 бп взят из рабочего допуска словаря; по коридорам он не разведён.
- Вторая кнопка названа «Уведомлять о новом сигнале», а не «Напомнить, когда курс вернётся»:
  «вернётся» — будущее время, его снимает чекер `fxmoment check-texts`.

## `journey.html` — путь из пуша в перевод

Один файл, CSS и JS внутри. Единственный внешний запрос — три `@font-face` на шрифт банка
(`alfabank.servicecdn.ru/media/fonts/alfa-interface-sans_{regular,medium,bold}.woff2`, `font-display: swap`);
файлы шрифта в репозиторий не копируются, офлайн страница падает на системный фолбэк той же метрики
и открывается двойным щелчком. Рамка та же, что у `index.html`: слева заголовок шага, в центре
телефон 390 × 844, справа панель «Действия» с кнопками текущего шага, внизу дисклеймер.

Восемь экранов переключаются панелью справа, клавишами <kbd>0</kbd>–<kbd>7</kbd> и параметром адреса
`journey.html?step=N`. Дополнительные параметры: `&ctx=changed` · `closed` — дата открытия пуша
(22.06 или 01.07); `&sheet=why` — открытая шторка «Почему это сообщение». <kbd>Esc</kbd> закрывает шторку.

| `?step=` | Экран | Что показывает |
|---|---|---|
| `0` | Пуш на блокировке | уведомление 09.06.2026, шаблон `level_stall`; три кнопки открывают тот же пуш в три даты |
| `1` | Экран перевода | факт, курс действия a_T, мини-график 90 дней публикации, «Почему это сообщение», способ перевода |
| `2` | Получатель | предзаполнение из истории переводов: номер, банк, назначение |
| `3` | Сумма | 30 000 ₽, пересчёт в сомони по курсу ЦБ, «Без комиссии» |
| `4` | Проверка перевода | к списанию, получатель получит, курс, комиссия 0 ₽ |
| `5` | Готово и вердикт | перевод подтверждён + карточка «Этот сигнал» с вердиктом по правилу 20 дней |
| `6` | Курс изменился | механика A: две цифры, разница в % и в ₽ на 30 000 ₽; первая строка говорит, выполняется ли факт |
| `7` | Напомним при новом сигнале | ветка B как действие внутри экрана A, а не второй пуш |

Развилка замкнута: с экрана `6` кнопка «Посмотреть курс сейчас» ведёт на экран `1` с текущим курсом
и пересчитанной суммой (`?step=1&ctx=closed` — тот же путь с курсом 01.07), «Напомнить при новом
сигнале» — на экран `7`. Нижняя панель вкладок видна на экранах 1–5, активна «Платежи».
